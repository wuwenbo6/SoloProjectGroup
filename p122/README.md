# 农具榫卯模型分析系统

一个基于 Three.js 的 3D 农具榫卯结构分析系统，支持模型加载、受力分析、形变模拟、疲劳强度计算和方案保存。

## 功能特性

### 1. 模型加载
- 支持 OBJ 格式模型文件
- 支持 JSON 参数化模型
- 内置默认榫卯结构演示模型
- 自动计算模型几何信息

### 2. 受力分析
- 计算最大/最小主应力
- von Mises 等效应力计算
- 弯曲应力分析
- 剪切应力计算
- 安全系数评估
- 应力着色可视化

### 3. 形变模拟
- 3D 变形可视化
- 实时动画演示
- 位移矢量箭头显示
- 可调节变形缩放系数
- 应力颜色映射

### 4. 疲劳强度计算
- S-N 曲线计算
- 雨流计数法 (Rainflow Counting)
- Miner 线性损伤累积法则
- Goodman/Gerber 平均应力修正
- 疲劳寿命预测
- 损伤评估

### 5. 方案保存
- localStorage 本地存储
- JSON 文件导出/导入
- 分析报告生成 (TXT 格式)
- 项目数据验证

```bash
npm run build
```

## 使用说明

### 1. 加载模型
- 点击工具栏「加载模型」按钮
- 选择本地模型文件（支持 .obj, .json）
- 或直接使用内置默认榫卯模型

### 2. 设置参数
- **材料参数**：
  - 弹性模量 (默认 12 GPa，木材)
  - 泊松比 (默认 0.35)
  - 密度 (默认 700 kg/m³)

- **载荷参数**：
  - 力大小 (默认 1000 N)
  - 力方向 (X, Y, Z 分量)

### 3. 执行分析
依次点击：
1. **受力分析** - 计算应力分布
2. **形变模拟** - 可视化结构变形
3. **疲劳计算** - 评估疲劳寿命

### 4. 保存方案
- 点击「保存方案」导出 JSON 文件
- 点击「加载方案」导入已有项目

## 技术栈

- **Three.js** - 3D 渲染引擎
- **Vite** - 构建工具
- **OrbitControls** - 相机控制
- 纯前端实现，无需后端

## 核心算法

### 应力分析
- 梁弯曲理论
- 材料力学基本方程
- 主应力计算
- von Mises 屈服准则

### 形变模拟
- 弹性变形理论
- 位移场计算
- 缓动函数动画

### 疲劳分析
- S-N 曲线拟合
- 雨流计数法
- Miner 法则
- Goodman 修正

## 注意事项

1. 本系统为演示版本，计算结果仅供参考
2. 实际工程应用请使用专业 CAE 软件验证
3. 木材材料参数因树种、含水率等因素差异较大
4. 榫卯接触行为简化处理，未考虑摩擦和间隙
