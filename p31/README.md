# 古建筑榫卯结构3D交互系统

## 项目概述

本项目是一个专注于古建筑榫卯结构的3D可视化与交互系统，集成了三维建模、拆解动画、受力分析和历史文献管理等功能，旨在为古建筑研究、保护和教学提供数字化工具支持。

### 核心功能模块

1. **3D模型建模模块** - 榫卯结构三维可视化展示
2. **榫卯拆解交互模块** - 分层拆解与装配动画
3. **后端数据管理服务** - SpringBoot RESTful API
4. **历史榫卯知识库模块** - 文献管理与关联

## 技术栈

### 后端
- **框架**: SpringBoot 2.7.x
- **ORM**: Spring Data JPA
- **数据库**: MySQL 8.0+
- **构建工具**: Maven
- **JDK版本**: Java 11+

### 前端
- **3D引擎**: Three.js r128
- **控件**: OrbitControls
- **加载器**: GLTFLoader
- **UI**: 原生HTML/CSS/JavaScript

## 快速开始

### 环境要求

- JDK 11+
- MySQL 8.0+
- Maven 3.6+
- 现代浏览器（支持WebGL）

### 后端启动步骤

1. **创建数据库**
```sql
CREATE DATABASE mortise_tenon_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. **修改配置**

编辑 `backend/src/main/resources/application.yml`，修改数据库连接信息：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mortise_tenon_db
    username: your_username
    password: your_password
```

3. **启动应用**
```bash
cd backend
mvn spring-boot:run
```

后端服务将在 `http://localhost:8080/api` 启动

### 前端启动步骤

直接用浏览器打开 `frontend/index.html` 即可

或者使用本地HTTP服务器：
```bash
cd frontend
python -m http.server 8081
# 访问 http://localhost:8081
```

### 新增高级功能

#### 1. 受力模拟可视化
- **应力分布显示**: 红-黄-绿三色热力图标识应力大小
- **荷载测试**: 支持压力、拉力、剪力三种荷载类型测试
- **强度调节**: 0-100%荷载强度连续可调
- **实时计算**: 根据拆解进度实时更新应力分布
- **变形模拟**: 线框模式显示构件变形程度
- **力向量箭头**: 箭头方向和长度表示受力方向和大小
- **数据面板**: 显示最大应力、安全系数、形变量等关键参数

#### 2. 拆解步骤录制与回放
- **屏幕录制**: 一键录制拆解全过程，包括相机视角和构件位置
- **本地保存**: 录制数据保存为JSON文件，支持离线查看
- **加载回放**: 加载历史录制文件，精确还原操作过程
- **速度调节**: 0.25x - 2.0x 播放速度连续可调
- **实时状态**: 显示录制帧数、预计时长等信息
- **断点续播**: 支持暂停、继续、清空录制内容

#### 3. 榫卯类型智能检索
- **全文检索**: 支持模型名称、分类、描述的模糊搜索
- **标签搜索**: 预制常用标签，点击即可快速检索
- **智能排序**: 根据匹配度加权排序显示结果
- **即时响应**: 输入即搜索，无需等待回车确认
- **结果高亮**: 搜索结果显示匹配度分数
- **一键加载**: 点击搜索结果直接加载对应模型

#### 4. 性能优化与设备适配
- **三级画质**:
  - 高性能: 最高精度几何、完整光照、阴影、抗锯齿
  - 中画质: 平衡性能与质量，适合主流设备
  - 低画质: 最低资源占用，适合低配移动设备
- **实时FPS监控**: 画面左下角显示实时帧率，颜色标识性能状态
- **渲染开关**:
  - 抗锯齿 (AA): 可开关，大幅影响性能
  - 阴影效果: 可开关，减少GPU占用
  - LOD动态加载: 距离相关细节级别
- **内存管理**: 切换模型时自动dispose几何体和材质，防止内存泄漏
- **防抖优化**: 窗口大小调整防抖处理，减少重绘次数
- **帧率独立动画**: 不同性能设备动画速度一致

## 使用说明

### 基本操作流程

1. 从下拉菜单选择一个榫卯模型
2. 使用鼠标拖拽旋转视角，滚轮缩放
3. 点击"开始拆解"查看结构拆解动画
4. 点击"应力视图"查看受力分析节点
5. 点击"关联文献"查看相关历史资料

### 交互控制

- **左键拖拽**: 旋转视角
- **滚轮**: 缩放视图
- **右键拖拽**: 平移视图
- **侧边栏按钮**: 控制拆解动画和视图

## 扩展开发

### 添加新的榫卯类型

1. 在数据库的 `t_mortise_tenon_type` 表插入新类型
2. 在前端 `app.js` 的 `modelData` 对象中添加模型数据
3. 配置构件几何形状和拆解路径
4. 添加受力分析节点数据

### 接入真实3D模型

1. 使用Blender、3ds Max等软件建模
2. 导出为GLTF/GLB格式
3. 上传到后端模型目录
4. 修改前端使用GLTFLoader加载真实模型

## 注意事项

1. 确保浏览器支持WebGL（现代浏览器均支持）
2. 首次加载模型可能需要几秒时间
3. 后端服务必须先启动，数据库连接正常
4. 文件上传目录需要确保有写入权限
