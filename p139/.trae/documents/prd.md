# 量子计算模拟器 - 产品需求文档

## 1. 项目概述

### 1.1 项目背景
构建一个全栈量子计算可视化模拟器，让用户能够通过拖拽式界面设计量子电路，实时观察量子态演化，并获取测量结果。

### 1.2 项目目标
- 提供直观的量子电路设计体验
- 实时可视化量子态在Bloch球面上的表示
- 支持高性能量子模拟（最多30个量子比特）
- 保存和管理历史电路记录

## 3. 非功能需求

### 3.1 性能需求
- 单量子比特电路响应时间 < 100ms
- 30量子比特模拟时间 < 10s（CUDA加速）
- 前端FPS保持在30以上

### 3.2 兼容性需求
- 支持Chrome、Firefox、Safari最新版本
- 响应式设计，支持桌面端

### 3.3 可靠性需求
- 任务队列容错机制
- 数据库事务保证数据一致性

## 4. 用户交互设计

### 4.1 主界面布局
```
┌─────────────────────────────────────────────────────────┐
│  导航栏：Logo | 历史记录 | 帮助                         │
├──────────────────┬──────────────────────────────────────┤
│                  │  Bloch球面可视化区域                 │
│  量子门工具箱    │  (Three.js 3D渲染)                   │
│  [H] [X] [Y] [Z] │                                      │
│  [CNOT] [Toffoli]│  量子态信息面板                      │
│                  │                                      │
├──────────────────┼──────────────────────────────────────┤
│                                                     │
│  量子电路编辑器（拖拽区域）                              │
│  q0: ────□─────⊕────── 测量                             │
│  q1: ────⊕─────│────── 测量                             │
│  q2: ──────────⊕────── 测量                             │
│                                                     │
├─────────────────────────────────────────────────────────┤
│  [运行电路] [清除] [保存]  |  概率分布图表  |  测量结果   │
└─────────────────────────────────────────────────────────┘
```

### 4.2 核心交互流程
1. 用户从工具箱拖拽量子门到电路线路
2. 系统实时计算并更新Bloch球面显示
3. 用户点击"运行电路"提交作业
4. 后端异步处理计算任务
5. 前端轮询获取结果并展示概率分布和测量结果

## 5. 数据需求

### 5.1 电路数据结构
```json
{
  "id": "uuid",
  "name": "电路名称",
  "qubits": 3,
  "gates": [

    {"type": "CNOT", "control": 0, "target": 1},
    {"type": "Toffoli", "controls": [0, 1], "target": 2}

}
```

```json
  "job_id": "uuid",
  "status": "completed",
  "state_vector": [...],
  "probabilities": {"000": 0.25, "001": 0.25, ...},
  "measurements": ["000", "010", ...],
  "execution_time": 1.23
}
```

## 6. 技术选型（初步）
- **后端框架**: FastAPI
- **量子模拟**: 自定义NumPy/CUDA实现
- **任务队列**: Celery + Redis
- **数据库**: SQLite (开发) / PostgreSQL (生产)
- **前端框架**: React + TypeScript
- **3D渲染**: Three.js
- **构建工具**: Vite
