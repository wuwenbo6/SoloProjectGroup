# 农田病虫害智能监测系统

基于边缘计算的农业病虫害AI监测系统，采用RK3588边缘设备进行实时图像/音频采集和AI推理，Go语言后端实现数据同步和归档，Vue3前端提供监控控制台。

## 项目架构

```

├── edge/                    # 边缘端AI推理模块
│   ├── device/             # 边缘设备接入管理

│   ├── feature/            # 病虫害特征提取
│   ├── inference/          # AI推理引擎
│   ├── storage/            # 本地数据存储
│   ├── communication/      # 跨设备通信
│   ├── main.py            # 边缘端主程序
│   └── requirements.txt   # Python依赖
├── backend/                # Go后端数据同步服务
│   ├── config/            # 配置管理
│   ├── models/            # 数据模型
│   ├── database/          # 数据库操作
│   ├── api/               # API处理器
│   ├── main.go            # 后端主程序
│   ├── go.mod             # Go模块定义
│   └── go.sum             # Go依赖锁定
├── frontend/              # Vue3前端监控控制台
│   ├── src/
│   │   ├── views/        # 页面组件
│   │   ├── App.vue       # 主应用
│   │   └── main.js       # 入口文件

│   └── package.json
└── database/             # 数据库分库存储
    └── schemas/         # 数据库schema
```

## 核心功能

### 边缘端 (RK3588)
- **设备接入管理**: 支持田间摄像头、虫情测报灯、音频传感器等设备接入
- **实时数据采集**: 图像和音频数据实时采集和预处理
- **特征提取**: 颜色直方图、LBP纹理、形状特征、MFCC音频特征
- **AI推理引擎**: 轻量级CNN图像分类、音频分类模型，支持离线推理
- **本地存储**: SQLite + 文件系统分库存储，支持数据缓存
- **数据同步**: 自动与后端同步推理结果和原始数据

### 后端 (Go)
- **数据同步服务**: 接收边缘端推理结果，批量处理
- **历史数据归档**: 数据分片存储，支持按时间查询
- **模型更新推送**: 模型版本管理，增量更新到边缘设备
- **异常预警**: 病虫害爆发预警，多级别告警
- **RESTful API**: 标准化API接口，支持前端和第三方集成

### 前端 (Vue3)
- **监控面板**: 设备状态、推理统计、图表可视化
- **病虫害分布**: 饼图展示各类病虫害识别占比
- **7日趋势**: 折线图展示推理数量趋势
- **识别结果**: 历史结果查询，支持按设备、病虫害类型筛选
- **预警信息**: 时间线展示预警事件，支持标记处理
- **知识库**: 病虫害详细信息和防治方法

## 快速开始

### 环境要求
- Python 3.8+
- Go 1.21+
- Node.js 18+
- SQLite3

### 1. 启动边缘端
```bash
cd edge
pip install -r requirements.txt
python main.py
```

### 2. 启动后端
```bash
cd backend
go mod download
go run main.go
```

后端服务将在 `http://localhost:8080` 启动

### 3. 启动前端
```bash
cd frontend
npm install
npm run dev
```

前端将在 `http://localhost:3000` 启动

## API 接口

### 数据同步
- `POST /api/v1/data/batch` - 批量上传采集数据
- `POST /api/v1/results/batch` - 批量上传推理结果

### 查询接口
- `GET /api/v1/results` - 获取推理结果列表
- `GET /api/v1/statistics` - 获取统计数据
- `GET /api/v1/alerts` - 获取预警信息
- `GET /api/v1/pest-knowledge` - 获取病虫害知识库

### 模型管理
- `GET /api/v1/models/latest` - 获取最新模型信息

## 数据库设计

### 采集数据表 (collected_data)
- 原始图像/音频数据元信息
- 设备ID、时间戳、数据类型、数据路径
- 支持按设备、时间、类型索引查询

### 推理结果表 (inference_results)
- 推理ID、数据关联ID
- 病虫害类型、置信度、模型类型
- 边缘节点ID、时间戳

### 预警信息表 (alerts)
- 预警级别、类型、消息
- 边缘节点、时间戳、处理状态

### 病虫害知识库 (pest_knowledge)
- 病虫害中英文名称
- 危害描述、防治方法
- 图片URL、相关文献

### 模型版本表 (model_versions)
- 模型类型、版本号
- 下载地址、校验和
- 发布说明、发布时间

## 技术特点

1. **边缘-云端协同架构**: 边缘端实时推理，云端集中管理
2. **离线-在线双模式**: 断网时本地缓存，联网后自动同步
3. **轻量级AI模型**: 针对RK3588优化，支持实时推理
4. **分库分表存储**: 原始数据和推理结果分开存储，高效查询
5. **增量模型更新**: 支持模型热更新，不中断边缘设备服务
6. **多租户支持**: 可扩展支持多农场、多区域部署

## 病虫害类型

系统支持以下常见病虫害识别：

- **蚜虫 (Aphid)**: 刺吸式害虫，传播病毒病
- **粉虱 (Whitefly)**: 刺吸汁液，诱发煤污病
- **蓟马 (Thrips)**: 锉吸式害虫，造成叶片银灰色
- **红蜘蛛 (Spider Mite)**: 叶螨科，造成叶片失绿
- **棉铃虫 (Bollworm)**: 鳞翅目害虫，蛀食果实
