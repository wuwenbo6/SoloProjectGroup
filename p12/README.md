# Unity 2D 电路沙盒模拟器

一个功能完整的 Unity 2D 电路模拟沙盒游戏，支持用户创建、编辑和保存电路设计。

## 功能特性

### 核心物理模块
- **直流电路模拟** - 支持电流、电压、功率的实时计算
- **电路节点系统** - 节点电压传播与求解算法
- **模块化元件架构** - 易于扩展新的电路元件

### 支持的电路元件
- **电源 (VoltageSource)** - 可调电压输出，支持 0-24V 调节
- **电阻 (Resistor)** - 欧姆定律实现，阻值 1-10000Ω 可调
- **电容 (Capacitor)** - 充放电模拟，电容值可调
- **二极管 (Diode)** - 单向导通特性，正向压降可调
- **导线 (Wire)** - 元件间连接，可视化电流指示

### 游戏场景模块
- **Tilemap 网格系统** - 元件对齐与网格放置
- **多种交互模式** - 选择、放置、连线、删除
- **元件旋转** - 按 R 键旋转选中元件
- **相机控制** - 滚轮缩放，中键拖拽

### UI 界面
- **元件选择面板** - 快速选择要放置的元件类型
- **参数设置界面** - 选中元件后可调节各项参数
- **状态实时显示** - 显示元件的电流、电压、功率等数值
- **模式指示器** - 当前操作模式实时提示

### 存档系统
- **JSON 格式存档** - 电路数据持久化保存
- **存档管理** - 保存、加载、删除电路设计
- **自动命名** - 基于时间戳的自动文件名

## 操作说明

### 基本操作
- **左键点击** - 根据当前模式执行操作（选择/放置/连线/删除）
- **右键点击** - 取消当前操作或取消选择
- **R 键** - 旋转选中的元件
- **Delete/Backspace** - 删除选中元件

### 相机控制
- **鼠标滚轮** - 缩放视图
- **鼠标中键拖拽** - 平移视图

### 元件放置流程
1. 点击左侧元件面板选择要放置的元件类型
2. 在场景中点击放置元件（自动对齐网格）
3. 选择连线模式，从一个元件的节点拖动到另一个元件的节点创建连接

### 参数调节
1. 选择模式下点击选中元件
2. 在右侧参数面板拖动滑块调节参数
3. 参数修改立即生效并重新计算电路

## 技术要点

- **物理引擎** - 自定义节点电压法求解器，迭代式电压传播
- **数据驱动** - 元件参数通过字典序列化，支持运行时修改
- **单例模式** - 各系统管理器采用单例模式，全局访问
- **事件驱动** - UI交互通过事件系统解耦
- **JSON序列化** - 存档数据采用 Unity JsonUtility 序列化
