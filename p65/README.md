# Unity 扎染游戏项目

一个以传统扎染工艺为核心玩法的2D模拟游戏，玩家可以选择布料、捆扎方式、染料颜色，模拟扎染过程并预览染色效果。

## 项目结构

## 核心功能模块

### 1. 核心染色物理模拟 (Core)
- **网格系统**：128x128可配置的像素网格，支持实时更新
- **颜色扩散算法**：基于湿度的颜色流动模拟，模拟真实染色过程
- **蒸发效果**：随时间推移的水分蒸发，影响颜色扩散速度
- **捆扎遮罩**：通过图案算法生成遮罩，模拟扎染的防染效果

### 2. 扎染素材模块 (Materials)
- **布料材质**：
  - 多种布料类型（棉、丝、麻等）
  - 不同的吸收速率和扩散特性
  - 基础颜色和纹理粗糙度设置
- **捆扎图案**：
  - 螺旋图案 (Spiral)：支持多臂螺旋
  - 靶心图案 (Bullseye)：同心圆环
  - 条纹图案 (Stripes)：水平、垂直、对角线
  - 折叠图案 (Folding)：手风琴、三角、方形折叠

### 3. 关卡模块 (Level)
- **渐进难度**：从简单到复杂的关卡设计
- **时间限制**：每关有时间限制，增加紧张感
- **染色次数限制**：限制染料使用次数
- **目标匹配**：与目标图案相似度评分
- **星级评价**：根据完成度给予1-3星评价
- **解锁系统**：完成关卡解锁新内容

### 4. UI交互模块 (UI)
- **主菜单**：玩家信息显示、关卡选择、自由模式
- **游戏界面**：
  - 颜色选择面板
  - 图案选择面板
  - 布料选择面板
  - 画笔大小/强度调节
  - 模拟控制（开始/停止/重置）
- **暂停界面**
- **完成/失败界面**：显示分数、相似度、星级

### 5. 存档模块 (Save)
- **玩家进度**：等级、经验、金币
- **关卡进度**：每关的最佳分数、星级、相似度
- **解锁内容**：已解锁的布料和图案
- **数据持久化**：使用PlayerPrefs存储，支持导入导出

### 6. 知识讲解模块 (Knowledge)
- **分类系统**：历史、技法、材料、图案、技巧
- **等级解锁**：根据玩家等级解锁新知识
- **图文并茂**：支持插图和详细说明
- **传统工艺知识**：介绍扎染的历史文化和传统技法

## 游戏玩法流程

1. **选择关卡或自由模式**
   - 关卡模式：有明确目标和限制
   - 自由模式：无限制，自由创作

2. **准备阶段**
   - 选择布料材质
   - 选择捆扎图案
   - 选择染料颜色

3. **染色阶段**
   - 使用鼠标/触摸在布料上染色
   - 调整画笔大小和强度
   - 可多次叠加不同颜色

4. **模拟阶段**
   - 启动颜色扩散模拟
   - 观察颜色自然流动效果
   - 随时可以停止模拟

5. **提交结果**
   - 系统计算与目标的相似度
   - 获得分数和星级评价
   - 解锁奖励和新知识

## 设置指南

### Unity环境要求
- Unity 2021.3 LTS 或更高版本
- 支持2D渲染
- TextMeshPro 包

### 初始设置

1. **创建单例管理器**：
   - 在场景中创建空对象，添加 LevelManager 和 LevelSaveData 组件
   - 确保标记为 DontDestroyOnLoad

2. **配置关卡数据**：
   - 创建 LevelData ScriptableObject
   - 设置关卡参数、可用颜色、图案、布料
   - 设置目标图案纹理

3. **创建知识条目**：
   - 创建 TieDyeKnowledge ScriptableObject
   - 填写标题、内容、分类、解锁等级

4. **设置UI**：
   - 配置 MainMenuUI 和 GameUI 组件引用
   - 设置按钮预制体和面板引用

### 扩展开发

**添加新图案类型**：
1. 继承 TiePattern 基类
2. 实现 ApplyToMask 方法，使用网格坐标生成遮罩
3. 在Unity编辑器中创建对应ScriptableObject

**添加新关卡**：
1. 创建新的 LevelData 资产
2. 配置关卡参数和目标图案
3. 添加到 LevelManager 的 allLevels 数组

**添加知识内容**：
1. 创建 TieDyeKnowledge 资产
2. 编写内容，可选添加插图
3. 添加到 KnowledgeManager 的 allKnowledgeItems 数组

## 核心算法说明

### 颜色扩散算法
```
每帧更新：
1. 遍历每个像素
2. 检查上下左右四个邻居
3. 计算湿度差（当前像素湿度 - 邻居湿度）
4. 如果湿度差 > 0，转移部分颜色和湿度
5. 转移量 = 湿度差 * 扩散率 * 时间增量
```

### 图案相似度计算
```
对于每个像素：
1. 获取目标颜色和玩家结果颜色
2. 计算RGB空间的欧氏距离
3. 归一化距离到0-1范围
4. 所有像素的平均值即为整体相似度
```

## 技术特点

- **模块化架构**：各模块独立，易于扩展和维护
- **事件驱动**：使用C#事件实现模块间通信，降低耦合
- **ScriptableObject数据驱动**：所有游戏数据可通过编辑器配置，无需改代码
- **性能优化**：模拟算法经过优化，支持移动平台
- **面向对象设计**：充分利用继承、多态等OOP特性
