# Bug 修复说明文档

## 修复问题列表

### 1. 驱动识别失败问题 (camera/driver.py)

#### 问题描述
- 老式胶片相机驱动识别不稳定
- USB设备枚举失败
- 串口连接波特率不匹配
- 连接重试机制缺失

#### 修复内容
1. **增强设备识别**
   - 添加胶片相机厂商ID识别列表
   - 支持设备描述关键词匹配
   - 设备列表优先显示胶片相机设备

2. **多波特率自动探测**
   - 自动尝试多种波特率连接串口设备
   - 支持 9600, 19200, 38400, 57600, 115200 bps

3. **连接重试机制**
   - 最多3次重试连接
   - 每次重试延迟0.5秒

4. **USB驱动增强**
   - 处理USB权限错误并提供日志
   - 支持内核驱动分离
   - 正确的接口声明管理

5. **完善日志系统**
   - 分级日志输出
   - 连接状态详细记录
   - 错误信息追踪

---

### 2. 图像失真与色彩偏差问题 (scanning/service.py)

#### 问题描述
- 扫描图像色彩偏移
- 白平衡不准确
- 图像细节丢失
- 色彩空间转换错误

#### 修复内容
1. **色温校正算法**
   - 基于Kelvin色温的RGB通道调整
   - 支持2000K-10000K色温范围
   - 模拟不同胶片的色温特性

2. **图像处理流水线优化**
   - 亮度/对比度调整 (np.clip防止溢出)
   - HSV色彩空间饱和度调整
   - 正确的图像类型转换 (float32 ↔ uint8)

3. **图像编码优化**
   - JPEG质量设置为85-90，平衡质量与传输速度
   - TIFF无损压缩保存
   - 添加分辨率元数据(300dpi)

4. **捕获设备初始化优化**
   - 根据分辨率设置正确的帧大小
   - 自动曝光控制优化
   - 缓冲区大小设置
   - 预读取帧稳定设备

---

### 3. 自定义参数保存后无法生效问题 (前后端)

#### 问题描述
- 扫描时未正确传递参数
- 参数应用逻辑不完整
- 参数配置和扫描流程脱节

#### 修复内容
1. **后端修复 (scanning/service.py)**
   - 扩展 ScanConfig 包含所有图像处理参数
   - 支持 profile_id 关联参数配置
   - 完整实现 apply_film_params 方法
   - 处理所有图像参数的顺序应用

2. **前端修复 (Scanning.tsx)**
   - 添加参数配置选择下拉框
   - 实时加载并应用保存的参数配置
   - 完整的高级参数调整界面
   - 所有参数通过API传递到后端

3. **参数传递流程**
   - 开始扫描时发送完整参数配置
   - 单帧捕获也支持参数应用
   - WebSocket实时状态同步

---

### 4. 批量转录进程卡死与文件损坏问题 (scanning/service.py)

#### 问题描述
- 长时间扫描后进程无响应
- 文件保存失败或损坏
- 线程异常终止
- 资源泄漏

#### 修复内容
1. **线程安全机制**
   - 使用 threading.Event 控制停止信号
   - 移除所有 asyncio.run 调用避免事件循环冲突
   - 使用消息队列 decouple 处理与广播

2. **后台广播Worker**
   - 独立的 asyncio 任务处理 WebSocket 广播
   - 防止主线程阻塞
   - 优雅的错误处理和恢复

3. **错误恢复机制**
   - 错误计数机制（最多10次错误自动停止）
   - 单帧失败不影响整体流程
   - 异常捕获和日志记录

4. **文件完整性保障**
   - 保存后验证文件存在
   - 检查文件大小有效性
   - 正确的文件写入参数

5. **资源正确释放**
   - 停止扫描时正确释放捕获设备
   - 线程超时等待机制
   - WebSocket连接正确关闭

6. **文件损坏防护**
   - TIFF文件写入参数优化
   - 文件大小验证
   - 异常情况下的回滚处理

## 性能优化

1. **内存使用**
   - 图像处理后及时释放资源
   - 避免不必要的图像拷贝
   - 使用 in-place 操作减少内存占用

2. **扫描速度**
   - 优化图像处理算法
   - 减少不必要的颜色空间转换
   - 平衡图像质量与处理速度

3. **稳定性**
   - 所有关键操作都有异常捕获
   - 优雅降级处理
   - 详细的错误日志便于调试

## 使用说明

启动后端服务：
```bash
cd backend
python server.py
```

启动前端开发服务：
```bash
npm run dev
```

所有修复均已集成到现有代码中，无需额外配置。
