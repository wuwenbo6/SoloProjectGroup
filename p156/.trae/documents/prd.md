# 供应链碳排放管理系统 - 产品需求文档 (PRD)

## 1. 产品概述
本系统为企业提供全面的供应链碳排放管理解决方案，通过导入供应链数据，基于EPA/IPCC标准系数计算范围一、二、三温室气体排放，实现碳足迹可视化追踪与智能减排决策支持。
- 主要目的：帮助企业量化碳排放、识别排放热点、制定减排策略、满足合规报告要求
- 目标用户：企业ESG管理人员、供应链分析师、可持续发展负责人
- 市场价值：助力企业实现双碳目标，降低碳风险，提升绿色竞争力

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 企业管理员 | 企业邮箱注册 | 数据导入、系统配置、用户管理、报告导出 |
| 普通用户 | 企业邮箱注册 | 数据查看、仪表盘分析、减排建议浏览 |

### 2.2 功能模块
1. **数据导入模块**：CSV/Excel文件上传、API数据接入、数据预览与校验
2. **碳排放计算模块**：EPA/IPCC系数管理、范围一二三排放计算、pandas聚合分析
3. **可视化仪表盘**：排放源构成饼图、趋势折线图、热点分布图、综合指标卡片
4. **减排建议模块**：行业基准对比、智能减排推荐、优先级排序
5. **报告导出模块**：PDF报告生成、图表嵌入、历史数据对比
6. **历史数据管理**：数据库存储、版本追溯、趋势分析

## 3. 核心流程
用户登录系统后，首先导入供应链数据（支持CSV/Excel/API），系统基于EPA/IPCC排放系数自动计算范围一、二、三的碳排放量，计算结果通过可视化仪表盘展示。用户可查看减排建议，选择时间范围和图表类型，最终导出包含分析图表的PDF报告。所有数据自动存储至数据库，支持历史追溯和趋势分析。

```mermaid

    A["用户登录"] --> B["数据导入<br/>(CSV/Excel/API)"]

    C --> D["EPA/IPCC系数<br/>匹配计算"]
    D --> E["范围一/二/三<br/>排放聚合"]
    E --> F["可视化仪表盘"]
    F --> G["减排建议<br/>基准对比"]
    G --> H["报告导出<br/>(含图表)"]
    H --> I["数据库存储<br/>历史记录"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深绿色 (#1B4D3E) - 代表环保与可持续发展
- **辅助色**：青绿色 (#2E8B57)、暖橙色 (#E67E22) - 用于数据突出和CTA按钮
- **中性色**：深灰 (#2C3E50)、浅灰 (#F8F9FA)、白色 (#FFFFFF)
- **按钮风格**：圆润直角 (border-radius: 8px)、悬停微放大效果、渐变填充
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- **布局风格**：卡片式布局、顶部导航栏、左侧菜单栏、网格系统
- **图标风格**：线性图标、统一圆角、24x24px 标准尺寸

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘页 | 概览卡片 | 渐变背景、数据大字、趋势小图、图标点缀 |
| 仪表盘页 | 图表区域 | 白色卡片、阴影效果、图表标题、图例说明 |
| 数据导入页 | 上传区域 | 虚线边框、拖拽图标、文件列表、进度条 |
| 减排建议页 | 建议卡片 | 分级颜色标识、进度条、量化指标 |
| 报告中心页 | 报告列表 | 表格布局、状态标签、操作按钮组 |

### 4.3 响应式
- **桌面优先**：1440px 断点，侧边栏展开，四列网格布局
- **平板适配**：1024px 断点，侧边栏可收起，两至三列网格
- **手机优化**：768px 断点，顶部汉堡菜单，单列布局，触控按钮增大至48px

### 4.4 动效设计
- 页面加载：卡片渐入动画 (fade-in + translateY)
- 数据更新：数字滚动计数动画
- 图表交互：悬停高亮、点击展开详情
- 按钮反馈：悬停缩放 1.03 倍，点击按下效果
