# 扎染工艺教育游戏 - Unity项目

## 项目简介

这是一个以传统扎染工艺为核心玩法的Unity教育游戏项目，通过数字化模拟真实的扎染过程，让玩家在游戏中学习和体验中国传统手工艺文化。

## 核心功能模块

### 1. 染色物理模拟 (DyePhysics)

**DyeSimulation.cs** - 核心染色引擎
- 基于网格的染料扩散算法
- 实时模拟染料渗透效果
- 支持多种颜色混合
- 捆扎区域防染效果
- 可调节扩散速度、蒸发率等参数

**FabricMesh.cs** - 布料网格系统
- 2D/3D布料网格生成
- UV坐标映射系统
- 材质纹理更新

### 2. 扎染素材系统 (Materials)

**FabricData.cs** - 布料数据
- 支持多种布料材质（棉、麻、丝等）
- 每种布料有独特的吸色和扩散特性
- 不同的视觉纹理效果

**DyeColor.cs** - 染料颜色
- 传统天然染料颜色库
- 包含文化含义说明
- 不同的染色强度参数

**TieMethod.cs** - 捆扎方式
- 4种基础扎法：折叠、螺旋、圆形、条纹
- 每种方式可生成不同复杂度的图案
- 包含详细步骤说明

### 3. 关卡系统 (Levels)

**LevelData.cs** - 关卡定义
- 关卡目标系统
- 素材使用限制
- 时间限制
- 评分标准（星级系统）
- 关卡提示与引导

**LevelManager.cs** - 进度管理
- 关卡解锁系统
- 星星收集机制
- 最佳成绩记录
- 关卡完成判定

### 4. UI交互系统 (UI)

**MainMenuUI.cs** - 主菜单
- 开始游戏、关卡选择、作品画廊、工艺知识
- 设置面板（音量、全屏等）

**LevelSelectUI.cs** - 关卡选择
- 网格状关卡展示
- 已解锁/未解锁状态显示
- 已获星星展示
- 关卡详情预览

**GameUI.cs** - 游戏主界面
- 布料选择面板
- 染料选择面板
- 捆扎方式选择
- 笔刷大小调节
- 模拟控制按钮
- 暂停/完成面板
- 实时倒计时和分数显示

### 5. 存档系统 (Save)

**SaveManager.cs** - 作品保存
- 自动保存扎染作品
- 作品元数据记录（使用的布料、染料、捆扎方式）
- 最多保存20个作品
- PNG格式导出功能

**GalleryUI.cs** - 作品画廊
- 网格状作品展示
- 作品详情查看
- 导出到桌面
- 删除功能

### 6. 工艺知识系统 (Knowledge)

**KnowledgeManager.cs** - 知识库管理
- 四大分类：历史渊源、工艺技法、材料知识、文化传承
- 9条预设工艺知识
- 等级解锁机制
- PlayerPrefs持久化存储

**知识内容包括：**
- 扎染的历史发展
- 传统天然染料介绍
- 折叠、螺旋、圆形等扎法教程
- 布料选择指南
- 大理白族扎染文化
- 日本绞缬工艺
- 现代扎染应用

## 游戏流程

1. **主菜单** → 选择开始游戏或浏览其他功能
2. **关卡选择** → 选择已解锁的关卡
3. **扎染过程**：
   - 选择布料材质
   - 选择捆扎方式并应用
   - 选择染料颜色
   - 使用鼠标/触摸在布料上涂抹染料
   - 点击开始模拟观察扩散效果
   - 调整并完成作品
4. **关卡完成** → 获得评分和星星奖励
5. **解锁内容** → 新关卡、新素材、新知识

## 技术特点

### 图形渲染
- 基于Texture2D的实时染色
- 支持512x512高分辨率纹理
- 流畅的扩散动画效果

### 物理模拟
- 8邻域扩散算法
- 基于湿度的渗透模拟
- 捆扎区域阻挡效果
- 可调节物理参数

### 数据持久化
- PlayerPrefs存储游戏进度
- JSON格式知识数据
- PNG格式作品保存
- 文件系统存储作品图片

### 架构设计
- 单例模式核心管理器
- 模块化组件设计
- 事件驱动UI更新
- 易于扩展的架构

## 教育价值

1. **传统文化传承** - 数字化展示中国传统扎染技艺
2. **工艺知识学习** - 图文并茂的技法讲解和历史文化知识
3. **创造力培养** - 自由创作模式激发艺术创造力
4. **寓教于乐** - 游戏化学习体验，让传统工艺更有趣

## Unity版本要求

- Unity 2020.3 LTS 或更高版本
- 支持Standalone、iOS、Android平台
- 需要UI、ImageEffects等标准模块
