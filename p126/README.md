# 纸张显微图像分析系统

一个基于计算机视觉的纸张显微图像分析平台，支持污渍检测、纸张类型分类、破损预测和批量推理功能。

## 功能特性

- 📷 **图像上传**: 支持拖拽上传和文件选择
- 🔍 **污渍检测**: 自动检测图像中的油污、水渍、霉斑、尘埃等污渍
- 📋 **类型分类**: 智能识别纸张类型（新闻纸、书写纸、打印纸、铜版纸、牛皮纸、宣纸、纸板等）
- 📊 **破损预测**: 分析纸张健康度，预测潜在破损风险
- ⚡ **批量处理**: 支持批量上传和多图像并行分析

## 技术栈

- **后端**: FastAPI + OpenCV + Pillow + NumPy
- **前端**: 原生 HTML5 + CSS3 + JavaScript (无需框架)
- **计算机视觉**: OpenCV图像处理、形态学分析、特征提取

## 快速开始

### 1. 启动后端服务

```bash
cd backend

# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 或者使用启动脚本
bash start.sh
```

后端服务将在 http://localhost:8000 启动

API文档地址: http://localhost:8000/docs

### 2. 打开前端页面

直接在浏览器中打开 `frontend/index.html` 文件即可：

```bash
# macOS
open frontend/index.html

# Windows
start frontend/index.html

# Linux
xdg-open frontend/index.html
```

## API接口说明

### 图像上传
- `POST /api/upload/` - 上传单张图片
- `GET /api/upload/{file_id}` - 获取已上传图片

### 污渍检测
- `GET /api/detection/{file_id}` - 检测图片中的污渍

### 类型分类
- `GET /api/classification/{file_id}` - 分类纸张类型

### 破损预测
- `GET /api/prediction/{file_id}` - 预测破损风险

### 批量处理
- `POST /api/batch/` - 批量处理多张图片

### 风化趋势预测
- `GET /api/weathering-trend/{file_id}` - 预测未来健康度变化趋势
- 参数: `prediction_months` - 预测月数（默认24个月）

### 多期对比
- `POST /api/compare/` - 对比两张图像的变化
- 参数: `file1_id`, `file2_id`, `time_diff_days` (可选)

### 维修量估算
- `GET /api/repair-estimate/{file_id}` - 估算维修费用和工时

### 模型切片
- `GET /api/model-slice/{file_id}` - 网格化分析图像
- 参数: `grid_rows`, `grid_cols` - 网格行列数（默认4×4）

## 检测算法说明

### 污渍检测
1. 图像预处理：灰度化、高斯模糊去噪
2. 阈值分割：OTSU自适应二值化
3. 形态学操作：开闭运算去除噪声
4. 轮廓检测：查找并筛选污渍区域
5. 特征分析：基于颜色和面积分类污渍类型

### 类型分类
- 亮度分析：基于灰度均值计算纸张亮度
- 纹理分析：拉普拉斯方差计算纹理粗糙度
- 纤维检测：Sobel边缘检测分析纤维可见度
- 颜色分析：RGB通道分析纸张色调
- 规则匹配：基于特征阈值匹配纸张类型

### 破损预测
- 边缘密度：高边缘密度预示纤维断裂风险
- 均匀度：灰度标准差反映纸张老化程度
- 饱和度：高饱和度区域可能存在霉菌侵蚀

## 使用说明

### 基本功能
1. 启动后端服务
2. 打开前端页面
3. 在"单图分析"标签页上传图片进行逐项分析或完整分析
4. 在"批量处理"标签页上传多张图片进行批量分析
5. 查看分析结果和可视化数据

### 高级功能

#### 风化趋势预测
1. 切换到"风化趋势"标签页
2. 上传需要分析的纸张图像
3. 选择预测周期（6、12、24、36、60个月）
4. 点击"开始预测"
5. 查看趋势图表、关键风险点和养护建议

#### 多期对比分析
1. 切换到"多期对比"标签页
2. 分别上传早期图像和后期图像
3. （可选）填写两次拍摄间隔天数
4. 点击"开始对比"
5. 查看各项指标变化对比（污渍数量、面积、健康度、亮度、纹理等）

#### 维修量估算
1. 切换到"维修量估算"标签页
2. 上传需要评估的纸张图像
3. 点击"开始估算"
4. 查看预估费用、工时、维修项目列表和材料清单

#### 模型切片分析
1. 切换到"模型切片"标签页
2. 上传需要分析的图像
3. 设置网格行列数（2×2到10×10）
4. 点击"开始分析"
5. 查看热力图、高风险区域和统计摘要

## 注意事项

- 建议使用高分辨率的显微图像以获得更准确的分析结果
- 确保图片光照均匀，避免反光和阴影
- 批量处理时建议单次不超过20张图片
- 如需更高精度的检测，可以基于实际样本训练专用机器学习模型
